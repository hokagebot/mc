Curve fitting · Parabola
Fit a second-degree parabola and estimate for 1998

Index of jute export prices, 1975–1979.

⌄

Question

Fit a second-degree parabola to the index of jute export prices using year as the independent variable. Also estimate for 1998.

YearYXX²XYX²Y
1975185-24-370740
1976169-11-169169
19771910000
197820311203203
1979275245501100
Total10230102142212

Fit the equation

Y = a + bX + cX²
ΣY = 5a + 10c → 1023 = 5a + 10c
ΣXY = 10b → b = 214/10 = 21.4
ΣX²Y = 10a + 34c → 2212 = 10a + 34c

Solving gives a = 180.8857, b = 21.4, c = 11.8571.

Fitted parabola: Y = 180.8857 + 21.4X + 11.8571X²

Estimate for 1998

X = 1998 − 1977 = 21
Y = 180.8857 + 21.4(21) + 11.8571(21²)
Y ≈ 5859.71

This is a long-range extrapolation from only five years of data, so the numerical estimate may be mathematically correct for the fitted parabola but is not necessarily a reliable real-world forecast.

Q20
Curve fitting · Exponential
Estimate sales for 1999 using exponential and quadratic curves

Company sales in lakhs of rupees, 1989–1995; compare residual sums of squares.

⌄

Question

Sales (₹ lakhs): 1989–1995 = 32, 47, 65, 92, 132, 190, 275. Estimate sales for 1999 using Y = abˣ and a second-degree curve. Compare using residual sum of squares.

(i) Exponential curve

Take X = Year − 1992, so X = −3, −2, −1, 0, 1, 2, 3. Take logarithms:

log Y = log a + X log b

Using least squares on the log values gives approximately:

a = 93.4056; b = 1.4270
Y = 93.4056(1.4270)ˣ

For 1999, X = 7:

Y = 93.4056(1.4270)⁷ ≈ 1125.26 lakhs

(ii) Second-degree curve

Y = a + bX + cX²
ΣY = 833; ΣX = 0; ΣX² = 28
ΣXY = 1082; ΣX²Y = 3346; ΣX⁴ = 196

Solving the normal equations gives approximately a = 91.5714, b = 38.6429, c = 6.8571.

Y = 91.5714 + 38.6429X + 6.8571X²

For 1999, X = 7:

Y ≈ 698.07 lakhs

(iii) Better fit

Compare the sum of squared residuals between actual sales and fitted sales. The exponential curve fitted to log sales and the quadratic fitted to sales are evaluated on different scales if the exponential residuals are calculated in log units. For a fair comparison, calculate both RSS values using original sales units.

Important: the earlier RSS figures (18.14 and 182.71) should not be treated as a fair direct comparison unless both are computed from residuals in the same original-sales scale. This page keeps the curve equations and estimates, but use a consistent RSS calculation if your teacher requires the comparison.
